# Agent 基础：从聊天到可控执行

## 1. Agent 是什么

Agent 不是“更长的提示词”，而是一个带控制循环的系统：模型理解目标，选择工具，读取工具输出，更新状态，再决定继续、暂停、请求人工确认或结束。

## 2. 四个核心部件

- **模型**：负责推理、规划与生成候选动作。
- **工具**：文件、终端、浏览器、数据库、邮件、日历、代码托管等外部能力。
- **状态**：任务输入、中间结果、错误、预算、权限与检查点。
- **控制策略**：决定何时调用工具、重试、回滚、交给另一个 Agent 或请求人类批准。

## 3. Skill 的位置

Skill 是一份可复用的操作知识：它规定何时触发、需要什么输入、按什么步骤做、如何验证、哪些风险必须停下来。不同平台对目录结构和元数据约定不同，因此“能看到链接”不等于“能直接加载”。

## 4. 新人最容易忽略的三件事

1. 模型没有天然权限；工具连接决定它真正能做什么。
2. 工具成功返回不等于任务正确完成；必须检查业务结果。
3. 越是不可逆的动作，越需要明确的人工确认和回滚方案。

## 5. 第一次实践

选一个只读任务，例如“扫描一个测试目录并生成文件清单”。记录输入、工具调用、输出文件和验证命令。确认这一闭环可靠后，再逐步增加写入能力。
