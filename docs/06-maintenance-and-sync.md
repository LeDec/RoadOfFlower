# 索引维护与同步

## 1. 单一上游不是永久策略

当前版本以 MIT 许可的 VoltAgent Awesome Agent Skills 作为初始来源。后续应增加官方仓库直连、失效链接检查、许可证状态和多来源冲突处理。

## 2. 同步流程

1. 固定上游提交。
2. 下载索引与许可证。
3. 解析并按规范化 URL 去重。
4. 生成 CSV、JSON、Markdown 和分类页。
5. 运行数量、唯一性、字段、链接和 README 一致性检查。
6. 人工审阅差异后合并。

## 3. 不自动做的事

- 不自动安装或执行外部 Skill。
- 不根据 README 描述推断安全性。
- 不覆盖作者许可证。
- 不把失联项目立即删除；先标记并保留审计记录。

## 4. 贡献方向

高价值贡献包括：补充官方来源、修正链接、标记归档项目、增加许可证信息、提供真实兼容性复现、改进中文检索词和编写领域使用案例。
