# 如何寻找与评估 Skill

## 1. 先写任务，不要先逛目录

用一句话写清输入、期望输出和不可接受的失败。例如：“读取本地 Markdown，生成带来源链接的中文摘要；不得上传文件。”

## 2. 搜索候选

```bash
python scripts/search_skills.py "markdown summary" --limit 20
python scripts/search_skills.py "github pull request" --category "GitHub"
```

## 3. 五维评估

| 维度 | 要问的问题 |
|---|---|
| 来源 | 是官方团队、维护者还是匿名社区条目？ |
| 权限 | 会执行命令、写文件、联网、读取密钥或操作账户吗？ |
| 依赖 | 是否要求额外 CLI、运行时、浏览器、MCP 服务或付费 API？ |
| 可验证性 | 是否给出明确输出、测试和失败条件？ |
| 活跃度 | 最近提交、Issue、兼容平台和许可证是否清楚？ |

## 4. 红旗

- 要求复制不明密钥或关闭安全检查。
- 使用 `curl | sh`、管理员权限或全盘写权限却没有解释。
- 没有许可证、来源、版本或验证步骤。
- 把“模型说完成了”当作唯一成功标准。

## 5. 试运行

在临时目录、测试账户和最小权限下运行。保留日志，比较变更前后差异，确认没有越权副作用，再决定是否进入正式工作流。
