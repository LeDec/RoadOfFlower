# 90 天行动计划

目标：完成一个小而可信的研究闭环，而不是同时启动十个宏大方向。

## 第 1 周｜问题与边界

从问题池选一个问题，写反证条件、目标用户、数据和风险。

### 本周交付

- 一个可链接的主要产物。
- 一条明确失败或未知。
- 一次独立检查或自动验证。
- 下周进入条件与停止条件。

### 日程建议

| 时间 | 动作 |
|---|---|
| 周一 | 设定问题与验收标准 |
| 周二—周三 | 执行最小实验或实现 |
| 周四 | 验证、复算和失败分析 |
| 周五 | 写作、整理、复盘与休息计划 |

## 90 天结束时只问五个问题

1. 原始问题是否仍然重要？
2. 核心假设获得了什么证据，又被什么限制？
3. 第三方能否复现？
4. 下一轮最值得投入的单一改进是什么？
5. 这 90 天是否以不可持续的健康和关系代价换来？
